# Site CGS

Site vitrine statique bilingue pour Carbure Global Service (CGS). La version française est à la racine du projet et la version anglaise se trouve dans `en/`.

## Utiliser le site

Ouvrir `index.html` pour la version française ou `en/index.html` pour la version anglaise. Le sélecteur de langue permet de passer d'une version à l'autre. Aucune installation ou compilation n'est nécessaire.

## Publier le site

Le code a été poussé sur le dépôt GitHub public [`realAronaba/cgs`](https://github.com/realAronaba/cgs), branche `main`. Le push ne publie pas le site sur le web : GitHub Pages devra être activé pour obtenir une URL publique. Il n'y a pas de commande de build; le dossier de publication est la racine du projet.

Avant publication, confirmer l'adresse de contact affichée dans les deux versions. Les consignes de développement, l'historique et les étapes détaillées de déploiement figurent dans [AGENTS.md](AGENTS.md).
