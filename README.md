# Site CGS

Site vitrine statique en français pour Carbure Global Service (CGS). La page présente le cabinet, ses expertises, sa méthode, ses engagements et ses clientèles.

## Utiliser le site

Ouvrir `index.html` dans un navigateur. Aucune installation ou compilation n'est nécessaire.

## Publier le site

Le code a été poussé sur le dépôt GitHub public [`realAronaba/cgs`](https://github.com/realAronaba/cgs), branche `main`. Le push ne publie pas le site sur le web : GitHub Pages devra être activé pour obtenir une URL publique. Il n'y a pas de commande de build; le dossier de publication est la racine du projet.

Avant publication, confirmer l'adresse de contact affichée dans `index.html`. Les consignes de développement, l'historique et les étapes détaillées de déploiement figurent dans [AGENTS.md](AGENTS.md).
